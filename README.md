# Planned Verification and Usability Tests

## Non-Functional Verification
- Performance: search response target within 3 seconds for at least 95% of 20 searches using 100 sample tutor profiles.
- Notification queue: mock notification queued within 60 seconds of relevant events.
- Reliability: prevent overlapping confirmed sessions.
- Security: role-based access and audit integrity.
- Privacy: hide contact details until a session is confirmed.

## Usability Scenarios
- UE-01: Search for a tutor and open the tutor profile.
- UE-02: Complete and submit a tutoring request.
- UE-03: Tutor reviews and accepts a pending request.
- UE-04: User finds reminders and changes notification settings.

Actual results should be recorded only after the tests are performed.
