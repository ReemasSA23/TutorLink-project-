# TutorLink – Peer Tutoring Platform

TutorLink is a university peer-tutoring project for **CpE-371: Software Engineering and Development** at Kuwait University.

## Project Overview
TutorLink helps university students find suitable tutors, submit tutoring-session requests, and manage confirmed sessions.

### Main Roles
- **Seeker** – searches for tutors and requests sessions.
- **Tutor** – publishes subjects/availability and accepts or declines requests.
- **Coordinator** – verifies tutors, handles policy exceptions, and reviews audit information.

### Main Features
- Search tutors by subject, time, and session format.
- Submit tutoring-session requests.
- Check booking rules before confirmation.
- Accept or decline tutoring requests.
- Cancel or reschedule sessions.
- Record important actions in an audit log.
- Provide mock notifications and reminders.
- Send reminders 24 hours and 1 hour before confirmed sessions.
